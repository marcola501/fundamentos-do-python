🐍 Tipos de Dados em Python

1. Inteiro (int)

Números inteiros, sem parte decimal.

idade = 25
numero = -10

2. Flutuante (float)

Números com ponto decimal.

altura = 1.75
preco = 19.99

3. String (str)

Sequência de caracteres de texto.

nome = "João"
mensagem = 'Olá Mundo'

4. Booleano (bool)

Valores verdadeiro ou falso (True/False).

ativo = True
deletado = False

5. Lista (list)

Coleção ordenada e mutável de elementos.

frutas = ["maçã", "banana", "laranja"]
numeros = [1, 2, 3, 4, 5]

6. Tupla (tuple)

Coleção ordenada e imutável de elementos.

coordenadas = (10, 20)
cores = ("vermelho", "verde", "azul")

7. Dicionário (dict)

Coleção de pares chave-valor.

pessoa = {"nome": "Maria", "idade": 30}
produtos = {"id": 1, "preco": 50.00}

8. Conjunto (set)

Coleção não ordenada de elementos únicos.

numeros = {1, 2, 3, 4, 5}
tags = {"python", "programação", "dados"}
