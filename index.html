Visão Geral dos Modelos de Rede

O que são Modelos de Rede?

Modelos de rede são frameworks que descrevem como diferentes protocolos e tecnologias de rede trabalham juntos. Eles dividem as funções de rede em camadas, facilitando o entendimento e a solução de problemas.

Por que dois modelos?

Modelo OSI: Criado como referência teórica para padronização. É excelente para aprendizado e compreensão de como as redes funcionam.

Modelo TCP/IP: Desenvolvido com base em protocolos reais da Internet. É o que realmente usamos nas redes modernas.

As 7 Camadas do Modelo OSI

O Modelo OSI (Open Systems Interconnection) divide as funções de rede em 7 camadas distintas, cada uma com responsabilidades específicas.

As 4 Camadas do Modelo TCP/IP

O Modelo TCP/IP (Internet) é mais prático e consolida algumas funções do modelo OSI em 4 camadas principais.

💡 Qual usar?

Para aprendizado: Use o modelo OSI. Suas 7 camadas fornecem uma visão mais detalhada de como as redes funcionam.

Para implementação: Use o modelo TCP/IP. É o que realmente funciona na Internet e redes modernas.

Para solução de problemas: Profissionais de rede usam o modelo OSI para diagnosticar problemas de forma sistemática, camada por camada.

Encapsulamento de Dados

Como os dados viajam pelas camadas

Quando você envia dados pela rede, cada camada adiciona suas próprias informações (headers) ao pacote. Este processo é chamado de encapsulamento.

📖 Glossário de Termos

OSI
Open Systems Interconnection - Modelo de referência com 7 camadas criado pela ISO
TCP/IP
Modelo prático de 4 camadas usado na Internet e redes modernas
PDU
Protocol Data Unit - Unidade de dados de protocolo em cada camada
Encapsulamento
Processo onde cada camada adiciona seus próprios headers aos dados
Desencapsulamento
Processo oposto onde cada camada remove seus headers
Header
Informação de controle adicionada por cada camada
Protocolo
Conjunto de regras que definem como dados são transmitidos
MAC Address
Endereço físico único de uma interface de rede (Camada 2)
IP Address
Endereço lógico único em uma rede (Camada 3)
Porta
Número que identifica um serviço ou aplicação (Camada 4)
